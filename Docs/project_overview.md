# RetailIQ - AI Powered Retail Intelligence Platform

## Overview

RetailIQ is an end-to-end Artificial Intelligence application developed to help retailers make data-driven decisions using Machine Learning, Deep Learning, and Generative AI.

The project consists of three independent AI modules integrated into a single Streamlit dashboard.

---

# Modules

## 1. Sales Forecasting

Purpose:
Predict future sales of a retail store.

Model Used:
XGBoost Regressor

Dataset:
Rossmann Store Sales Dataset

Output:
Predicted daily sales.

---

## 2. Product Recommendation

Purpose:
Recommend products to customers based on historical purchasing behavior.

Model Used:
Artificial Neural Network (Neural Collaborative Filtering)

Dataset:
Online Retail II Dataset

Output:
Top-N personalized product recommendations.

---

## 3. Product Classification

Purpose:
Classify retail product images into different categories.

Model Used:
MobileNetV2 using Transfer Learning

Dataset:
Fashion Product Dataset

Categories:
- Apparel
- Accessories
- Footwear
- Personal Care

Output:
Predicted product category with confidence score.

# Objective

RetailIQ demonstrates how multiple Artificial Intelligence models can work together inside a single business application.

The project combines:

- Machine Learning
- Deep Learning
- Recommendation Systems
- Computer Vision
- Generative AI
- Retrieval Augmented Generation (RAG)

to provide an intelligent retail analytics platform.
