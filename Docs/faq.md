# Frequently Asked Questions

## What is RetailIQ?

RetailIQ is an end-to-end AI-powered retail analytics platform that combines Machine Learning, Deep Learning, Computer Vision, and Generative AI into a single application.

---

## Which AI models are used?

* XGBoost
* Artificial Neural Network
* MobileNetV2
* Gemini
* FAISS

---

## Why are different models used?

Each business problem requires a specialized AI model.

Forecasting → Regression

Recommendation → Deep Learning

Classification → Computer Vision

Question Answering → RAG

---

## What is RAG?

Retrieval-Augmented Generation retrieves relevant project documents before sending context to the Large Language Model, reducing hallucinations and improving answer quality.

---

## What is FAISS?

FAISS is a vector similarity search library developed by Meta. It stores embeddings and quickly retrieves the most relevant document chunks.

---

## Why LangChain?

LangChain simplifies building RAG pipelines by connecting document loaders, text splitters, embedding models, vector databases, retrievers, and LLMs.

---

## Why Gemini?

Gemini offers fast inference, strong reasoning capabilities, good LangChain support, and a generous free tier.

# README Knowledge Summary

RetailIQ is a portfolio project demonstrating the integration of Machine Learning, Deep Learning, Computer Vision, Recommendation Systems, and Generative AI into a unified Streamlit application. The project showcases XGBoost for forecasting, Neural Collaborative Filtering for recommendations, MobileNetV2 for image classification, and a RAG-based Project Assistant powered by FAISS and Gemini to answer questions grounded in project documentation.
